# Mall Customer Dataset
This repository contains a data analysis and customer segmentation project using the **Mall Customer Dataset**. The primary goal is to explore the data and group mall customers into distinct segments based on their demographics and spending habits.

---

## 📊 Dataset Overview
The dataset contains information about customers collected through a local mall membership program. It includes the following features:

* **CustomerID:** Unique ID assigned to each customer.
* **Gender:** Gender of the customer (Male/Female).
* **Age:** Age of the customer.
* **Annual Income (k$):** Annual income of the customer in thousands of dollars.
* **Spending Score (1-100):** Score assigned by the mall based on customer behavior and spending nature.

---

## 🎯 Project Objectives
* Perform Exploratory Data Analysis (EDA) to find patterns and trends.
* Segment customers using machine learning clustering algorithms (e.g., K-Means, Agglomerative Clustering).
* Provide actionable marketing insights based on the identified customer personas.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
